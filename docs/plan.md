## Главная цифра для жюри

«Без MoneyGate ассистент помогает заплатить мошеннику в X из 36 случаев. С MoneyGate — в Y. Законные платежи проходят в Z из 36.»
Считать **честно**: отдельно показывать, сколько остановил судья, а сколько мандат (ссылки и карта всегда идут человеку).

## Риски

- Ключ Meta придёт только 26.10 → до этого всё проверяется на локальной модели или FakeJudge.
- Ложные тревоги на законных переводах родственникам (L02) — это и есть сложный случай, показать его открыто.
- Muse Spark может отвечать прозой вокруг JSON — парсер уже терпит обёртки и `<think>`.
